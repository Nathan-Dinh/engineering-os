# Phase 4: Quality-attribute workshop

Follow `${CLAUDE_PLUGIN_ROOT}/reference/rubrics/quality-attributes.md`. Start with context-specific questions, such as latency expectations, usage and growth, acceptable downtime and data loss, authorization and sensitive data, maintenance ownership and change frequency, accessibility expectations, and operating budget. Ask a small group per turn.

Have the user rank or compare the most important attributes. Never manufacture precise weights. Turn the top drivers into measurable scenarios whose targets come from evidence or explicit user acceptance.

Record in `docs/architecture/quality-attributes.md`, using `${CLAUDE_PLUGIN_ROOT}/reference/templates/quality-scenarios.md`. Then assess checkpoint B.
