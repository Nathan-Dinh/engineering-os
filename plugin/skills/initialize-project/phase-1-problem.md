# Phase 1: Problem, users, and success

Ask first what problem is being solved, who experiences it, and what outcome would count as success. Then establish the primary use cases, expected usage patterns, MVP essentials versus optional scope, and what is explicitly out of scope. Ask what is most uncertain.

Distinguish user outcomes from proposed features: "users need to find past orders quickly" is an outcome; "add a search bar" is a feature.

Record in `docs/PROJECT.md`: "Problem and users" and "Scope", labeled user-provided with the date. Keep open questions in `docs/STATE.md`.
